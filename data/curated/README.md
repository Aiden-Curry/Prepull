# Curated gear authoring data

CSV files in this directory are human-authored inputs. They reference normalized item IDs rather than duplicating item metadata. Use the curated import, export, template, and inspect commands from the repository root.

The manifest registry identifies every supported authored dataset and is the source used by import, validation, snapshot, support-matrix, and coverage tooling. Fury Warrior, Frost Mage, Combat Rogue, Marksmanship Hunter, and Holy Priest contain reviewed rankings. Protection Warrior remains a schema template only and intentionally contains no rankings.
